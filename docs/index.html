Мозг, который доказывает, а не угадывает.

Noema — нейросимвольный движок: LLM предлагает решение, Z3 проверяет его формально. Листайте — пройдём по отделам мозга, и в каждом вы увидите, как устроена его часть Noema.

отдел01

Здесь рождается решение

prefrontal cortex · /think

Префронтальная кора у человека отвечает за рассуждение и планирование. У Noema это точка входа /think: языковая модель предлагает гипотезу, а решатель Z3 обязан доказать её формально — иначе ответ не засчитывается.

  • LLM-провайдеры: OpenAI, Anthropic, Ollama
  • формальная верификация через Z3 до отдачи ответа
  • chain-of-thought с наблюдаемыми шагами рассуждения
  • Fallback-провайдер без ключей — демо и CI работают из коробки
POST /think → гипотеза LLM → Z3 proof → ответ с доказательством
отдел02

Здесь живёт память

hippocampus · memory & knowledge

Гиппокамп переводит опыт в долгосрочную память. Noema хранит эпизоды рассуждений и наращивает knowledge graph: движок помнит свои выводы и опирается на них в следующих сессиях.

  • эпизодическая память: запросы и их исходы
  • knowledge graph: сущности и связи между ними
  • поиск по прошлым доказательствам вместо повторного вывода
CLI: memory — эпизоды · knowledge — граф · graph — операции
отдел03

Здесь оттачиваются навыки

cerebellum · kernels & pipeline

Мозжечок доводит движения до автоматизма. У Noema это ядра (kernels) — упакованные умения, которые собираются в pipeline: шаг за шагом, каждый со своей зоной ответственности.

  • kernels: генерация кода, работа с знаниями, доменные модули
  • pipeline: композиция ядер в маршрут рассуждения
  • «evolve» — самоцикл улучшения навыков
CLI: pipeline — маршрут ядер · evolve — цикл самосовершенствования
отдел04

Здесь пульсируют жизненные функции

brainstem · gateway & providers

Ствол мозга держит дыхание и сердцебиение. Ствол Noema — gateway: маршрутизация к провайдерам, отслеживание переезда кредов, doctor-диагностика, встроенный fallback, который дышит даже без внешних ключей.

  • единая резолюция «какой провайдер обслужит эту модель»
  • doctor-CLI: диагностика окружения и конфигурации
  • fallback-провайдер — демо и CI поднимаются без ключей
CLI: serve — API на :8000 · doctor — проверка здоровья · health — самочувствие

отдел05

Здесь полушария говорят друг с другом

corpus callosum · grid federation

Мозолистое тело соединяет два полушария. У Noema это gRPC-федерация: инстансы объединяются в grid и делятся знаниями и вычислениями.

  • grid federate — соединение узлов в распределённый мозг
  • общий knowledge между инстансами
  • gRPC-транспорт поверх FastAPI-сервиса
noema grid federate --peer localhost:50051
отдел06

Здесь стоят защитные оболочки

meninges · security & observability

Мозг защищён тремя оболочками. У Noema это периметр безопасности: rate limiting, API-ключи с per-tenant квотами, tool_policy для MCP, RFC 7807 для ошибок и Prometheus-метрики поверх всего.

  • rate limiting и API-ключи на каждом запросе
  • MCP-транспорты http/SSE с политикой инструментов
  • request timeout guard + Prometheus /health/metrics
  • Unicode mojibake gate — сломанный юникод не проходит CI
GET /health/metrics → Prometheus · ошибки → RFC 7807
